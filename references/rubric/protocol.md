# 第三层 rubric 总协议（读这个文件后再进各 pass）

三层门禁的前两层（指标、lint）是机器的；这一层是你的判断。判断的质量取决于纪律，不取决于聪明。

## 审查纪律（不可违反）

1. **一次只读一组特征。** 自由铺开地读会让注意力塌缩到一两个显眼维度。按顺序执行三个 pass，每个 pass 只看该 pass 清单里的问题：
   - `narrative.md` — 叙事架构（结构层，最深）
   - `discourse.md` — 话语层（段落与推进方式）
   - `style-pass.md` — 表面层（机器 lint 之外的语感问题）
2. **No quote, no signal.** 每条信号必须引用原文短语（≤20 字）并给出位置（开头/中段/结尾）。引不出来的不算信号，直接丢掉。
3. **不重新跑机器的门禁。** 指标红项、lint 阻断项已经在 `qa/chNNN_gate.json` 里，不要重复报。你只查机器查不到的。
4. **不过度矫正。** 检出的每条信号标注「阻断」或「参考」两档：
   - 阻断：结构性问题（因果断裂、读者已知泄漏、视角崩坏）——必须修
   - 参考：倾向性问题（可以更好，但当前成立）——记入反哺，不强制改
5. **数值只是语料参照。** 本协议中的任何比例/频率数字是人类语料的参照区间，不是逐章硬阈值；不要把「出现了」直接判成「超标」。
6. **审完即收。** 每个 pass 产出不超过 5 条信号；没信号就写「本 pass 无阻断级发现」。

## 输出格式（追加到 qa/chNNN_rubric.md）

```markdown
# 第N章 rubric 报告

## Pass 1 · 叙事架构
- [阻断|参考] 信号名：引用「原文短语」（位置）→ 修复方向一句
...

## Pass 2 · 话语层
...

## Pass 3 · 表面层
...

## 结论
阻断级发现 X 条（列出）；反哺建议 Y 条（将并入 changes 的 anti_patterns_new）
```
