# Pass 3 · 表面层 rubric

先读 `protocol.md`。机器 lint 已经查过禁词句式与复读，本 pass 只查 lint 的正则覆盖不到的三件事。

## S1 朗读测试

把开头 300 字和结尾 200 字默读一遍，标出拗口处：连读会喘不上气、节奏赶、同音字扎堆。

- 信号：标注出的拗口处 ≥3 处
- 方向：在拗口处拆句或换词，以读出声为准

## S2 意象复读

lint 只能查逐字重复，查不了同义意象复读：同一个画面（雨/烟/影子/灯光）反复以不同措辞出现。

- 信号：同一意象在本章出现 ≥4 次或连续 3 章每章都当主角意象
- 方向：保留最有力的一处，其余换成别的感官（声音/触感/气味）

## S3 对话腔区分度

遮住说话人标签，能否分辨谁在说话？所有人的对话一个腔（同样句长、同样用词雅度）。

- 信号：连续两段对话遮住标签后无法归属
- 方向：对齐人物卡的 speech_print（口头禅/句长/语气词禁用表）

## S4 信息密度均匀感

每段承载的信息量均匀（都是"交代一件事"），没有空镜段、没有信息密集段的对比。

- 信号：全章段落的"每段推进一件事"完全均匀
- 方向：允许一段纯感官空镜，一段密集冲突，制造密度起伏

## 引用要求

每条信号：`[阻断|参考] S2 意象复读：引用「原文短语」（位置）→ 方向一句`。S3 涉及人设崩坏的（说的话违反角色 DO/DONT）升为阻断。
