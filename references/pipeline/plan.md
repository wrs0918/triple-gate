# 开新书协议（全局规划）

适用于用户说「开新书」。规划产出直接决定后面几百章的上限，宁慢勿糊。

## 1. 初始化

```bash
python scripts/tg.py init --title 书名 --genre 题材 [--platform fanqie]
```

## 2. 市场对标（可选但强烈建议）

请用户提供素材（榜单截图文字、对标书的章节文本、题材偏好），然后：

1. 分析题材热度与竞争密度：同题材在榜多少本、头部写法是什么。
2. 找 2-3 本对标书，拆解其开篇钩子、金手指设计、更新节奏。
3. 产出保存到 `plan-market.md`（书籍工作区根目录），一页以内。

没有素材时不要编造市场结论——直接进入书魂卡，并在卡里注明「未做市场对标」。

## 3. 书魂卡（北极星，与作者协作敲定）

直接编辑 `state/state.json` 的 `book.north_star`（planning 阶段允许）。五项全部具体，任何一项模糊就退回重新问：

| 字段 | 问题 | 拒绝标准 |
|---|---|---|
| positioning | 题材定位与目标读者 | 「都好看」=模糊；要能回答"给谁看、替代品是谁" |
| core_conflict | 核心矛盾：对手是谁、为何对抗、赌注 | 无具体对手或无赌注 → 退回 |
| power_cost | 主角能力与代价 | 能力无代价/限制 → 退回（无代价=无张力） |
| differentiation | 与具体爆款的差异 | 没提到具体书名 → 退回 |
| city_industry | 城市/行业与不可替代性 | 换城市不影响剧情 → 退回 |

## 4. 大纲与人物

- 大纲：填 `outline/outline.md`，前 20 章逐章条目（含五问占位），之后允许卷级粗纲（写前再细化当章条目）。
- 人物：直接编辑 `state/state.json` 的 `characters`（主要角色 2-4 个，配角按需）。每个角色必填 `speech_print`（语言指纹：句长习惯、口头禅、禁用词），后面每章对话对齐用。
- 文风基准：`state/style_baseline.paragraph` 暂空——第 1 章定稿后回填一段最能代表本书语感的 100-200 字。

## 5. 进入写作

```bash
python scripts/tg.py start
```

五项书魂卡有任何一项为空都会被拒绝。通过后停在「写第1章」等用户确认。

## 规划阶段红线

- 书魂卡五项在写作阶段不可擅自修改；作者要改，改完重跑 `tg start` 校验（planning 才允许编辑）。
- 不要在规划阶段写任何正文。
